## 1. Light & Dark Mode

**Critical rule: Do NOT directly invert colors between modes.**

Design each mode independently:

Light mode:
- Backgrounds should be close together (white, off-white, luminous light gray #F5F7FB)
- Ambient illumination provides depth and crisp separation
- Text: near-black (#1D1D1F) on luminous light surfaces

Dark mode:
- Backgrounds need distinct separation between levels (#1C1C1E, #2C2C2E, #3A3A3C)
- Accents should be brighter and vibrant (#0A84FF)
- Text: off-white (#F5F5F7) on dark surfaces

## 2. Color System
- Level 0 (base): Window canvas
- Level 1 (sections): Sidebar, top bars, toolbars
- Level 2 (cards): Translucent liquid glass panels with fine 0.5px rim borders
- Accent: System Blue (#007AFF light / #0A84FF dark) for interactive highlights and primary action pills

## 3. Typography
- SF Pro Display / SF Pro Text with clean geometry, tight letter spacing (-0.2px to -0.6px on titles).

## 4. Blur, Vibrancy & Liquid Glass
- Translucent frosted glass fills (85-90% opacity with ambient tint)
- Top specular highlight border (0.8px - 1.2px bright highlight rim)
- Ambient dual-layer shadows for soft floating depth

## 5. Shadows & Depth
- Layered shadows: subtle 0.5px perimeter outline + soft ambient spread
